Automation · Analytics · Oct 2026

Automated Weekly Sales Report

A Python tool that cleans sales files (CSV/Excel), builds an HTML report with charts and emails it every Monday, flagging sharp changes.

  • 540Kreal sales rows
  • ~25 sfull run
  • 8 → 3false alerts
  • 40automated tests
  • Tested on 540,000 real transactions (UCI Online Retail). Processes the full dataset in about 25 seconds and logs every dropped row with its reason.
  • Found and fixed errors that skewed the results. Shipping fees showed up as the best-selling product (£206,000), cancellations weren't subtracted, and an incomplete month looked like a 70% drop.
  • Cut false alerts from 8 to 3 over 11 weeks by comparing against a 4-week average instead of the previous week.
  • Runs 40 pytest tests on GitHub Actions and is scheduled with Windows Task Scheduler and WSL.
  • Python
  • pandas
  • Matplotlib
  • SMTP

Clinic App: Management & Booking Marketplace

A complete web app for a multi-branch clinic with 24/7 online booking, scheduling, patient records, point of sale, marketing, inventory, reports and payroll.
